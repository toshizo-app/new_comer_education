# 新人エンジニア心得帖 🌱

SESで働く新人エンジニアへ向けた、技術より先に身につけたい「報告・相談・成長」のための7章。

## 📖 内容

技術的なノウハウではなく、信頼される新人になるための心構えをまとめた読み物形式の心得集です。

- **Chapter 01** 「わかりません」と言える勇気
- **Chapter 02** ホウレンソウは、愛だ
- **Chapter 03** 質問は最強のスキル
- **Chapter 04** SESエンジニアの作法
- **Chapter 05** 失敗は、最高の教材
- **Chapter 06** 1年後に化ける人の習慣
- **Chapter 07** 最後に、君へ
