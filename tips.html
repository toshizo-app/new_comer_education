📝 報告テンプレ集

コピペで使える、シーン別のひな形。慣れたら自分の言葉に変えていこう。

朝の始業報告（Slack / Teams）

おはようございます。本日の予定です。

▼今日やること
・〇〇画面の××実装（昨日の続き）
・△△レビュー対応

▼相談したいこと
・〇〇の仕様で迷っている点を午前中にご相談させてください

よろしくお願いします。

💡 「相談したいこと」を入れるだけで、先輩は予定を空けてくれる。

日報（夕方の締め）

お疲れさまです。本日の報告です。

▼完了したこと
・〇〇機能の実装（PR #123 提出済み）

▼進行中
・△△の調査（進捗60%、明日完了予定）

▼困っていること／要相談
・××のエラーで詰まっています。明日朝、共有させてください

▼明日の予定
・調査続きと△△の実装

以上です。

💡 結論 → 進行中 → 困りごと → 明日 の順。1分で書ける構造に。

遅刻・体調不良の連絡

お疲れさまです。〇〇です。
本日、体調不良のため△時頃まで遅れての出社/リモートとさせてください。
ご迷惑をおかけし申し訳ありません。

▼影響
・本日予定のXXは△時以降に着手します
・緊急の案件があればSlackでご連絡ください

よろしくお願いいたします。

💡 謝罪より先に「いつから動けるか」「影響範囲」。相手が知りたいのはそこ。

エスカレーション（やばい！と思ったとき）

お忙しいところすみません、至急ご相談です。

▼何が起きているか
・〇〇環境で△△エラーが発生しています

▼影響範囲（わかる範囲で）
・××機能が使えない状態の可能性

▼今やっていること
・ログを確認中、原因切り分け中

▼判断いただきたいこと
・お客様への一報をこのタイミングで入れるべきか

5分後に状況更新します。

💡 「至急」と明示 + 判断してほしいことを明確に。原因究明より先に報告。

有給・休暇申請

お疲れさまです。
△月△日（〇）、有給休暇をいただきたく申請いたします。

▼当日の業務影響
・進行中の××は△日までに区切りをつけます
・緊急時の連絡先：△△さん（事前に共有予定）

ご確認のほどよろしくお願いいたします。

💡 申請は「権利」だが、影響を整理して伝えると「配慮できる人」になる。

💬 便利フレーズ集

言いたいけど、どう言えばいいかわからない。そんなときの一言。

🙋 認識を確認したいとき

「念のため確認させてください。〇〇という理解で合っていますでしょうか？」

🤔 反対意見を伝えたいとき

「ご提案ありがとうございます。一点気になる点があるのですが、××のケースだとどうなりますでしょうか？」

⏳ 時間がほしいとき

「すぐにお答えできず申し訳ありません。10分ほどお時間いただいて、整理してからお返事してもよろしいでしょうか？」

❓ 質問の前置きに

「初歩的な質問で恐縮ですが、〇〇について教えていただけますか？」

🙏 助けてもらったあと

「ありがとうございました。〇〇という流れで進めるとうまくいきました。とても勉強になりました」

📅 タスクを引き受けるとき

「承知しました。完了は△日の△時頃を見込んでいます。問題があれば早めに共有します」

⛔ 無理な依頼を受けたとき

「ご依頼ありがとうございます。現在〇〇を進めていて、両立が難しそうです。優先順位をご相談させてください」

🔄 進捗を聞かれたとき

「現在△%です。△時間後に完了見込みです。詰まっている点はないので、このまま進めます」

🚨 困ったときの処方箋

パニックになる前に、深呼吸してこれを開こう。

🔥 本番でやらかしてしまった
  1. 深呼吸（30秒）。パニックのまま動くと二次被害を生む
  2. すぐ報告。「やらかしました、今影響確認しています」だけでいい
  3. 事実だけ整理。何時に・何を・どうした。推測と事実を混ぜない
  4. 影響範囲を確認。可能なら自分で、無理なら先輩と
  5. 復旧。順序を先輩と相談してから動く（焦ると更に壊す）
  6. 再発防止を一緒に考える。「自分を責める」より「仕組みを変える」
📚 専門用語が飛び交って会議についていけない
  1. 会議中は わからない単語をメモだけ しておく
  2. 会議後すぐに先輩や同期に「あのとき出た〇〇って何ですか？」
  3. 同じ単語が3回出てきたら、 もう聞いていい合図
  4. 調べてもわからないとき、Slackで 「初歩的ですみません、〇〇について教えてください」 でOK
  5. 用語集を自分で作る。1ヶ月後には宝物になる
⏰ 期限に間に合いそうにない
  1. 気づいた瞬間に報告。前日や当日に言うのが最悪
  2. 「△日かかりそうです。理由は××です」と 原因と見込み をセットで
  3. 選択肢を3つ用意する: 「①期限延長 ②スコープ縮小 ③人を増やす」
  4. 判断は先輩・上司に委ねる。あなたは 情報提供係 でいい

💡 期限を守れないより、期限を守れない可能性を黙ってる方がはるかにマズい。

😡 お客様（or 先輩）が怒っている
  1. まず聞く。反論したくなっても、まず最後まで聞く
  2. 事実を確認。「〇〇という認識で合っていますか？」
  3. 謝るべきは謝る。ただし「自分のせいではない」ことまで謝らない
  4. 「次にどうするか」を提案。怒っている人は対策を聞きたい
  5. 一人で抱えない。報告して、先輩と一緒に対応する

💡 怒りの裏には「期待」がある。期待してくれている、と思って向き合おう。

😔 自分だけできていない気がする
  1. 同期と比べない。3ヶ月前の自分と比べる
  2. できないことより、 できるようになったことを毎日1つ書く
  3. 先輩に「何ができていれば及第点ですか？」と聞いてみる（基準が見えると楽になる）
  4. 誰でも最初は同じ。 3年目の先輩も、3年前は今のあなただった
💻 環境構築でハマって1日溶けた
  1. 15分ルール。15分詰まったら、誰かに聞く
  2. 聞くときは エラーメッセージのスクショ + やったこと をセットで
  3. 解決したら 必ずメモ。次の新人があなたに感謝する
  4. 環境構築は新人の通過儀礼。落ち込まなくていい

🗣 ミーティング小ワザ

会議は、新人にとって最大の学習機会。受け身じゃもったいない。

📝 議事録は積極的に立候補

「新人なので議事録やります」は最強のカード。話の流れと専門用語が一気に身につくうえに、先輩から「あいつ動けるな」と思われる。

🎤 発言は「質問」から始める

意見が出せなくても、質問はできる。「ひとつ確認させてください」と切り出すだけで、参加している感が出る。沈黙より、的を外した質問のほうがはるかにマシ。

⏰ 5分前には準備完了

オンライン会議は「カメラON、マイクOFF」で5分前にスタンバイ。先輩はそういう細かいところを見ている。

🎯 終わる前に「ToDoの確認」

会議の終わりに「私の宿題は〇〇と△△ですね？」と確認する。認識ズレの90%はここで防げる。

📤 議事録は当日中に共有

翌日になると記憶が薄れる。完璧じゃなくていい。速さは正義。後で訂正すれば良い。

🛠 新人に贈るおすすめツール

無料 or 安価で、最初の1年に確実に効くもの。

毎日の学びを蓄積する場所。 検索できる外部脳 を持つと人生が変わる。

⌨️ ターミナル

Warp / iTerm2

最初に触るターミナルはこだわっていい。 1日30回開くツール だから。

🧠 思考整理

Markdownで書く習慣

ツールより先に習慣。 箇条書きで考える人 は会議でも強い。

⏱ タイマー

ポモドーロ（25分集中 + 5分休憩）

集中力は鍛えるもの。「あと25分」と区切るだけで生産性が上がる。

📚 読書

「リーダブルコード」

新人時代に1冊だけ読むなら、これ。 コードは読まれるために書く を学べる。

📡 情報収集

Zenn / Qiita / X

毎日5分でいい。同じ職種の人がどんな悩みと向き合っているかを知る。
