## 📞 電話・対面編

### 電話を取るときの第一声

```
「お電話ありがとうございます。〇〇株式会社の△△でございます」
```

> 💡 名乗らないNG: 「もしもし」「はい、〇〇です」

---

### 取次ぎの一言

```
「××の件ですね。担当の△△に代わりますので、少々お待ちください」
```

```
「あいにく△△は席を外しております。
 戻りましたら折り返しお電話差し上げますが、よろしいでしょうか？

```

- 〇〇機能を追加 / △△バグを修正

## 背景
- なぜこの変更が必要か（Issue #123 を参照）

## 変更内容
- 〇〇.ts に △△ロジックを追加
- ××.ts の挙動を修正（before: A、after: B）

## 確認手順
1. 〇〇画面を開く
2. △△ボタンをクリック
3. ××が表示されることを確認

## レビュー観点
- 〇〇の実装方針が妥当か
- △△の命名がわかりやすいか

## 関連

- 参考: [リンク]
```

### コミットメッセージのパターン

```
feat: 〇〇機能を追加
